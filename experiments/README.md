# 実験

後の評価・agent・小規模LoRA-SFT実験を置く場所です。現時点で実験コードや実験結果はありません。

実験を始めたら、例えば `physics_eval_v1/` や `lora_sft_v1/` のように目的ごとのフォルダを作り、それぞれのREADMEに以下を記録します。

- 対応する週とタスク番号、何を比較するか。
- データ・モデル・設定と、変更した条件。
- 実行方法、使用した環境。
- 小さな結果・図・ログの場所と、分かったこと・残った疑問。

大きなデータ、モデルの重み、キャッシュなどは `.gitignore` で除外しています。必要な設定や小さな比較結果は残し、大きな成果物の保存先と再実行方法を記録してください。
