# 学習メモ

- [W02.md](W02.md)：複数特徴量の線形回帰、オフラインの成果物、質問のメモ。
- [physics_task_seed.md](physics_task_seed.md)：W01-13の物理題材の5項目と、W02-08の入力・出力整理。

メモからNotebook・図・コードへ相対リンクを付けると、後の週次更新で実績を確認できます。公開範囲が未定の研究内容は、Gitの対象外である `private/` に置いて記録できます。
